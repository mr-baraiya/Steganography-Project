Key Security & Privacy

AES-inspired 16-bit passcode key hashing and 10-byte binary header validation ensure maximum data integrity and security.

Header Protocol Specification

CELATUS prepends a 10-byte binary header to the LSB bit stream prior to pixel injection:

Bytes 0–3: Signature 0x43 0x45 0x4C 0x41 ('CELA')
Bytes 4–5: Key Checksum 16-bit Passcode Hash
Bytes 6–9: Payload Size 32-bit Integer Length
Bytes 10+: UTF-8 Stream Payload Data Stream
